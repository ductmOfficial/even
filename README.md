# Even

[![CI](https://github.com/ductmOfficial/even/actions/workflows/ci.yml/badge.svg)](https://github.com/ductmOfficial/even/actions/workflows/ci.yml)

A local-first personal finance ledger: double-entry bookkeeping, multiple currencies, shared expenses and debts. The whole database runs in the browser, so the app works offline and financial data stays on the device.

Work in progress. Requirements: Node.js 24 and pnpm 12.

```bash
pnpm install
pnpm turbo run lint typecheck test build
```
